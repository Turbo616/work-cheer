使用指南

几件小事，先说清楚。

简单开始，安心使用。

怎么开始使用？

Mac 打开 DMG，将应用拖入“应用程序”；Windows 运行 EXE 完成安装。打开后点击“设置”，填写月薪、作息和工作日，即可开始。无需注册。

安装时提示未知开发者怎么办？

Mac 版 v1.0.3 已修正旧版无效签名，但仍未完成 Apple Developer ID 签名和公证，因此系统可能阻止打开。Windows 也可能提示未知发布者。请确认从本页链接的 GitHub Release 下载并核对校验值。Mac 可在“系统设置 → 隐私与安全性”查看允许打开选项；Windows 可查看文件来源后自行决定是否继续。不要关闭系统安全保护。

收入是怎么算的？

正常时薪＝月薪÷月计薪天数÷每日有效工时，休息时段不计薪。工作日下班后的收入按你设置的加班时薪计算；休息日按单独时薪和当天作息估算。本月累计按当前作息估算历史工作日，再加今天收入和手动调整，不自动补入历史加班、请假或法定节假日。暂不支持跨夜班，仅供鼓励与参考，请以实际工资单为准。

会上传我的工资吗？

不会。桌面版不需要账号，工资和作息保存在当前设备，离线即可运行。网页试用版将设置保存在当前浏览器，没有工资上传接口。

真的免费吗？

免费使用，无广告，源码采用 MIT 协议开放。你也可以从 GitHub 查看、修改并自行构建。
